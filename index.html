AmazonPO Drive Mirror

AmazonPO Drive Mirror is a private, internal tool. It is not a public service and is used by a single dedicated account.

What it does with Google Drive:

  • Reads files in one Google Drive folder tree that has been shared with the tool account, and keeps a local copy for internal record keeping.
  • Creates new files in that same folder tree. It does not edit or delete existing files.

The tool does not sell, share, or transfer Google user data to third parties, and does not use it for advertising.
