Privacy Policy — AmazonPO Drive Mirror

Last updated: 2026-11-18

Who uses this app

AmazonPO Drive Mirror is a private, internal tool. It is authorized only by one dedicated tool account. It is not offered to the public.

Google user data the app accesses

  • Google Drive files and folders in one folder tree that has been shared with the tool account (file names, metadata, and file contents).

How the data is used

  • Files are read and copied to a local, access-controlled computer for internal record keeping.
  • New files are created in the same folder tree. The app does not modify or delete existing files.
  • Data is used only to provide these features. It is not used for advertising, is not sold, and is not used to train AI models.

Sharing

Google user data is not shared with or transferred to any third party, except as required by law.

Storage and security

Access tokens are stored only on the local computer that runs the tool, outside of any source code repository. Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
